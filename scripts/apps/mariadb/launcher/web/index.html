数据目录

当前位置— 将迁移到—
安装参数里的数据目录和数据库实际所在位置不一致。点上面的按钮把数据搬过去： 会短暂停止数据库 → 复制 → 逐项核对文件数和字节数 → 校验通过后才切换 → 在新位置启动。数据量大时可能要几分钟，期间别关页面。
中途任何一步失败都不会动到原数据，数据库仍会在原位置启动。 迁移成功后旧数据也会保留（目录名加 .migrated- 时间戳后缀）， 确认新位置一切正常后可以手动删除。

网络

关闭时监听 127.0.0.1，NAS 上的其它应用（Halo、WordPress 等）照常可以连， 但你从电脑上用 Navicat 连不上。开启前需要先把 root 密码改成你自己设定的。

root 密码

修改密码需要短暂停止数据库（通常几秒到十几秒），期间连接会中断。 即使忘记了当前密码也能改 —— 这里走的是不校验权限的维护通道。
