迁移数据目录

    
安装参数里的「数据保存目录」改过了，但数据还在原来的位置。

    

    

      迁移会：停止数据库 → 复制 → 逐个文件核对数量和字节数 → 核对通过才切换配置 →
      把旧目录改名成 .migrated-时间 保留 → 在新位置自动启动。

      任何一步失败都会退回原位置，原数据全程不会被删除。
