# ANI-RSS 绿联 UGOS Pro 版 · 使用教程

适用版本：3.1.78 及同系列原生 upk（含内置 Temurin JRE、中文路径修复）  
上游项目：https://github.com/wushuo894/ani-rss  
官方文档：https://docs.wushuo.top

---

## 一、安装前准备

### 1. 确认 NAS 架构

在绿联系统「控制面板 / 关于」等位置查看 CPU 架构，选择对应安装包：

| 架构 | 安装包文件名示例 |
|------|------------------|
| x86_64 / amd64 | `amd64_com.wushuo.anirss_3.1.78.xxxx.upk` |
| ARM64 | `arm64_com.wushuo.anirss_3.1.78.xxxx.upk` |

装错架构会无法运行，请务必核对。

### 2. 开发者授权（侧载 upk 必需）

若你尚未开通开发者安装能力，请先完成：

1. 向绿联申请开发者授权（通常需要：设备序列号、MAC、管理员用户名）。
2. 将下发的 `ugdev.sig` 放到 **管理员个人文件夹**。
3. 固件 1.16 及以上：在系统「应用开发」相关设置中 **启用开发者/侧载**。
4. 完成后，应用中心才支持手动安装 `.upk`。

### 3. 建议一并准备

- 已安装并可用的下载器（推荐 **qBittorrent**，也可用 Transmission / Aria2 等）。
- 一块用于存放番剧/下载的 **共享文件夹**（后续要授权给本应用，并与下载器挂载路径尽量一致）。

---

## 二、安装应用

1. 打开绿联 **应用中心**。
2. 选择 **手动安装 / 本地安装**（文案因固件略有差异）。
3. 选中对应架构的 `.upk` 文件并安装。
4. 安装完成后在应用列表中找到 **ANI-RSS**，点击启动。
5. 使用 **打开** 或桌面图标，系统会以浏览器新标签访问 WebUI（默认端口 **7789**）。

也可在同一局域网电脑浏览器访问：

```text
http://<你的NAS的IP>:7789
```

---

## 三、首次登录与安全

1. 打开 WebUI 后，使用默认账号登录：
   - 用户名：`admin`
   - 密码：`admin`
2. **立刻修改密码**（设置 / 账号相关页面，以实际界面为准）。
3. 若开启了外网访问或端口转发，务必使用强密码，并考虑仅内网使用。

---

## 四、授权目录（非常重要）

原生应用默认 **不能** 随意读写你的全部共享盘，需要你在系统里授权。

1. 打开绿联系统中该应用的 **设置**（应用中心或应用详情里的设置入口）。
2. 找到 **授权文件夹 / 访问路径** 一类选项。
3. 授权你的媒体库、下载目录（可多个），例如：
   - 下载缓存目录
   - 番剧库目录（最终归档位置）
4. 授权后，系统会把路径挂到应用可访问区域；应用侧也可通过共享目录环境使用这些路径。

> 若下载路径仍指向不存在的 `/Media/...`，请在 ANI-RSS 网页设置里改成你 **实际授权** 的路径。

---

## 五、连接下载器（以 qBittorrent 为例）

1. 确认 qBittorrent 已启动，WebUI 可登录（记下地址、端口、账号密码）。
2. 进入 ANI-RSS WebUI → **设置 / 下载设置**（名称以界面为准）。
3. 选择下载器类型为 **qBittorrent**。
4. 填写：
   - 主机地址（例如 `http://127.0.0.1:28080` 或 NAS 局域网 IP + 端口）
   - 用户名、密码
5. 保存后测试连接；能登录且状态正常再继续。

### 路径一致原则（硬链 / 刮削常用）

ANI-RSS 与下载器看到的 **同一部番的物理路径应一致**。  
例如：下载器保存到 `/volume1/Media/番剧`，则 ANI-RSS 的下载/完结路径模板也应使用同一套真实路径（或授权后两边都能访问到的同一目录）。  
两边路径对不上时，容易出现「任务下了，但整理/硬链失败」。

---

## 六、配置下载与媒体路径

在 ANI-RSS 设置中检查并修改：

1. **下载目录模板**（季番、剧场版、已完结等，按你的库结构填写）。
2. 是否自动重命名、是否删除种子、做种策略等（按个人习惯）。
3. 代理（若访问部分站点需要）。
4. TMDB / 刮削相关选项（需要时可填 API Key）。

保存后建议重启一次应用，再添加订阅，避免旧配置缓存干扰判断。

---

## 七、添加订阅并自动下载

### 方式 A：RSS 订阅（常用）

1. 在 ANI-RSS 中选择 **添加订阅 / 添加番剧**。
2. 粘贴 RSS 地址（如 Mikan、Anime Garden 等站点的订阅链接，以你实际使用的源为准）。
3. 确认标题、季数、字幕组等识别结果。
4. 保存后，应用会按设定间隔拉取 RSS。
5. 有更新时自动下载种子并推送到下载器。

### 方式 B：其它添加入口

若界面提供搜索、导入、批量添加等，按页面提示操作即可；核心仍是：**订阅存在 → 出种 → 推下载器**。

### 怎么确认已经推成功

1. 打开 qBittorrent 任务列表，应出现对应种子/任务。
2. 若只有订阅、下载器里没有任务，到 ANI-RSS 日志或系统应用日志中查看是否有报错。

---

## 八、日常使用建议

1. **保持 ANI-RSS 与下载器同时运行**，否则只能订阅不能落地下载。  
2. 磁盘空间不足时优先清理下载缓存与已完结转移策略。  
3. 改完下载器密码后，记得同步改 ANI-RSS 里的下载器配置。  
4. 升级 upk 前可先导出/备份配置（配置一般在应用 `data` 目录）；同系列升级通常会保留 data。  
5. 外网勿裸奔 7789 端口；需要远程时用 VPN 或反代 + 鉴权。

## 九、日志与排错

### 日志在哪

- 应用标准输出一般由系统收到：`log/com.wushuo.anirss.log`（路径在应用数据区 / 诊断包中）。  
- 业务配置：`data/config/config.v2.json`。  
- 种子缓存目录多在：`data/config/torrents/` 下。

### 常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 打不开网页 | 未启动 / 端口被占 / 防火墙 | 应用中心确认运行；访问 `IP:7789` |
| 默认密码进不去 | 已改过密码 | 用你设置的密码；必要时查配置或重置（会丢配置，慎用） |
| 下载器登录失败 | 地址/账号/HTTPS 不一致 | 用浏览器先验证 qB WebUI，再抄到 ANI-RSS |
| 有订阅无下载任务 | 过滤规则过严 / RSS 无匹配 / 路径失败 | 看日志；放宽过滤；检查种子目录是否写出 |
| 中文番名报 unmappable characters | 旧包未修编码 | 升级到带中文路径修复的 build（如 3.1.78.0002+），完全停启后再试 |
| 文件下了但库里乱 | 两边路径不一致 | 统一 ANI-RSS 与下载器保存路径 |

### 启动编码是否正常（进阶）

新版本启动日志中应能看到类似：

```text
sun.jnu.encoding = UTF-8
file.encoding = UTF-8
```

若仍是其它编码且中文路径报错，请换用已修复的安装包并 **完全停止后再启动**。

## 十、卸载与数据

- **卸载应用**：在应用中心卸载；是否删除数据以系统提示为准。  
- **仅清空配置**：停止应用后处理 `data` 目录（操作前请备份）。  
- **换机迁移**：可打包 data 配置与授权路径规划，并在新机器重装同 app_id 版本后恢复（细节因固件而异）。
