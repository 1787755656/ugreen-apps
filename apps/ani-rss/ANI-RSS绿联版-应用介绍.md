# ANI-RSS 绿联 UGOS Pro 版 · 应用介绍

ANI-RSS 是一款面向追番场景的自动化工具：通过 RSS 订阅番剧更新，自动识别资源、下载种子并推送到 qBittorrent、Transmission、Aria2 等下载器，同时支持刮削、重命名与洗版等能力，把「找种 → 下载 → 归档」尽量交给程序完成。上游项目开源在 GitHub（wushuo894/ani-rss），社区文档与讨论完善，适合作为 NAS 家庭媒体库的自动追番入口。

本包是针对 **绿联 UGOS Pro 原生应用中心** 重新打包的版本，不是简单拷贝 Docker 镜像。绿联应用沙箱默认没有 Java 运行环境，因此安装包内已捆绑 **Eclipse Temurin JRE**（仅运行时、非完整 JDK），双架构（amd64 / arm64）均可安装使用，无需你在系统里再装 Java。应用以独立非 root 用户运行，配置与数据落在可写目录，Web 管理界面默认端口 **7789**，在应用中心打开后即可在浏览器中操作。

与「只跑容器」相比，原生 upk 更贴近绿联应用中心的安装、启停与权限模型：可按需授权共享文件夹作为媒体/下载目录，并与同机已安装的下载器配合。打包时已处理中文路径编码问题（常见于中文番名写种子文件），避免出现「下载器能登录、却推不过种子」的情况。适合已经在用绿联 NAS、希望少碰命令行、把追番流程收进应用中心的用户。

**一句话**：自动追番 + 内置 Java 运行时 + 适配绿联原生应用沙箱，装好授权目录、连上你的下载器就能用。
