壁纸登录背景桌面壁纸库

桌面壁纸与登录背景一样，每次刷新（含下面的定时刷新）都会自动更换：登录页背景立即生效，同时新图写入壁纸库（bing_日期.jpg）并自动设为所有用户的桌面壁纸，全程无需手动点选确认（原壁纸指针自动备份，可一键还原）。想临时换成库里任意一张，点下方缩略图即可，单击立即生效。具体换哪些由下面的「同步模式」决定。首次修改前自动备份原版登录背景。

文件管理增强以文本方式打开

非必要不使用：UGOS Pro 10 月系统更新已内置该项能力，基本能满足日常需求。仅在你的系统版本确实没有「以文本方式打开」时才需要打补丁。
给 UGOS「文件管理」右键菜单加一项「以文本方式打开」，用官方文本编辑器打开 .toml、Dockerfile、.conf、无扩展名等任意文件。补丁前自动备份，可一键还原；官方更新文件管理后补丁会被覆盖，回这里再点一次即可。
  • 不改官方文件：补丁另存为一个新文件名，只把 index.html 的引用换过去，原 bundle 一个字节都不动。
  • 因为文件名变了，浏览器和 PC 客户端都会当成新文件重新下载——不用强刷、不用清缓存。
  • 备份里的永远是原版；还原会把 index.html 换回去并删掉补丁文件。
  • 若同时装着「以文本方式打开」浏览器插件，右键菜单会出现两项，二选一保留即可。

使用须知

  • 图标与登录背景修改前自动备份到应用数据目录；卸载应用前请先「还原」，否则备份随之删除。
  • 桌面壁纸跟随定时刷新自动更换（与登录背景同步），原指针自动备份，可用「恢复原桌面壁纸」一键还原。
  • 更换壁纸后若登录页没变，是浏览器缓存，强刷（Ctrl+Shift+R）即可；仍无变化请换一个浏览器登录查看。
  • 数据目录建议在安装时选到共享文件夹（如 Docker 目录下新建文件夹），重装不丢备份。
