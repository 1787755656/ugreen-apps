壁纸登录背景桌面壁纸库

「刷新 Bing 壁纸」同时更新两处：登录页背景立即生效；桌面壁纸写入壁纸库（bing_日期.jpg）。点击下方缩略图可直接设为桌面壁纸——修改的是每个用户的壁纸指针（原指针自动备份，可一键还原），桌面刷新或重新登录后生效。首次修改前自动备份原版登录背景。

使用须知

  • 图标与登录背景修改前自动备份到应用数据目录；卸载应用前请先「还原」，否则备份随之删除。
  • 更换壁纸后若登录页没变，是浏览器缓存，强刷（Ctrl+Shift+R）即可。
  • 数据目录建议在安装时选到共享文件夹（如 Docker 目录下新建文件夹），重装不丢备份。
